# Eval corpus photo prompts

One-time generation (16 images, 1024x1024 JPEG, quality low; medium for the three text images IMG_1011-1013; no recurring cost).
Model: gpt-image-2.5-sunburst via the imagegen skill. Every job also carries
`use_case: photorealistic-natural`, constraints "no recognisable faces, no brand names or logos, no watermark".

Command (from eval/, jobs file in the session scratchpad, one JSON object per line with the prompt and `out` below):

```
~/.claude/skills/imagegen/scripts/with_azure.sh python3 ~/.claude/skills/imagegen/scripts/image_gen.py \
  generate-batch --input photos.jsonl --out-dir corpus/photos --concurrency 4 --no-augment
```
